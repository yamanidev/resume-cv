## About
This repository contains my resume generated by the [RenderCV](https://docs.rendercv.com/) engine, which uses a YAML source file to produce the output files. The resume is built automatically via GitHub Actions on every push and published to [GitHub Releases](https://github.com/yamanidev/resume-cv/releases/latest).

- View online: [mohamedyamani.com/resume](https://mohamedyamani.com/resume/)
- Download PDF: [Mohamed_Yamani_resume.pdf](https://github.com/yamanidev/resume-cv/releases/download/latest/Mohamed_Yamani_resume.pdf)

## Usage
> **Requires Python 3.12+.** Use whichever command points to Python 3.12 or later on your system (e.g. `python`, `python3`, or `python3.12`).

- Create a virtual environment and activate it:
```
python -m venv venv
source venv/bin/activate
```
- Install the dependencies:
```
pip install -r requirements.txt
```
- Generate the resume:
```
rendercv render Mohamed_Yamani_resume.yaml
```

- Watch for changes and rebuild automatically:
```
rendercv render Mohamed_Yamani_resume.yaml --watch
```

Output files are placed in the `rendercv_output/` directory. To control which formats are generated, update the [`settings`](https://docs.rendercv.com/user_guide/yaml_input_structure/settings/) field in the YAML source file.
